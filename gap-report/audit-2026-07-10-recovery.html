The GPA slide is reversed, and five real security holes are closed.

Three confirming audits (passes 4-6) had walked the quality GPA down from 3.28 to a nadir of 2.77 - partly harsher grading each pass, partly 17 regressions a fast parallel gap-close had introduced. Two focused iterations turned it around. Iteration 1 invested in the untested platform layers (+287 real unit tests, low-risk by construction), lifting four subsystems and taking the GPA to 2.94. Iteration 2 fixed the real quality-capping defects, and in doing so the confirming-audit discipline earned its keep spectacularly: it caught five escalating security vulnerabilities in the ACK/purge path - up to a network-wide denial-of-delivery of §39 PRIVATE messages - each surfacing only after the prior fix looked complete. All five are closed with revert-proven tests. Quality GPA is back to 2.99 and climbing; 5 subsystems rose this round.

03

The five security fixes (r7-r11)

One finding - an unauthorized relay purge / ACK forgery - took five fix rounds and six confirming audits. Each new vector surfaced only AFTER the prior fix looked complete. This is the confirming-audit discipline paying for itself.
r7Traced-ACK authenticated but not authorized✓ closed
Vector
A signed ACK from any observer (not the destination) forged Delivered + stopped retransmit. Origin+relay now require signer == the acked bundle Device(dst).
r8Private-chimera ACK✓ closed
Vector
A private-flagged ACK has an attacker-chosen src (verify binds only the payload). It slipped past r7. Now the ACK must be identity-signed.
r9Traced-ACK naming a default private send✓ closed
Vector
The default §39 send is Broadcast-held with a cleartext id; a genuine signed AckTo naming it forged delivery. Fixed with a positive Device==signer match.
r10Private replay with a rewritten dst (ROOT)✓ closed
Vector
The private id binds only the payload, so a replay with dst=Device(attacker) shared the id and could pre-seed + purge a real message network-wide. verify() now enforces private => Broadcast at the gate.
r11Forged response-handler purge✓ closed
Vector
HttpResponse/ServiceResponse/HnsAnswer purged an attacker-named id with no auth - a network-wide DoS of a private message outside the ACK path. Now purge only OUR own sends.
